# Indian Tech Market Tracker

A dashboard showing tech job demand in India: top roles, cities, in-demand skills and posting trends.

**Pipeline:** Python script -> SQLite -> Streamlit + Plotly dashboard

> Note: this version uses randomly generated sample data, not real job listings.

## Run
1. `pip install -r requirements.txt`
2. `python scraper.py`   (generates 200 sample jobs)
3. `python -m streamlit run app.py`
